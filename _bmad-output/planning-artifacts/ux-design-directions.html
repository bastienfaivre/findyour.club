Key decisions

No listing on the main site — only country entry points. Stats replace the directory. Each country button links to its own subdomain with country-specific search.

Architecture

Subdomains per country: ch.platform-name.com, fr.platform-name.com, etc. The main domain is global landing + philosophy. Country domains host the actual directories.

Growth signal

"Coming soon" country buttons make the global vision tangible from day one. They validate the philosophy ("this is infrastructure, not a local app") and prime word-of-mouth from early Swiss clubs.

Country-specific fields

Switzerland: Canton is the primary geographic filter. France would use Département or Région. Germany: Bundesland. Each country domain has its own field schema — no one-size-fits-all form.

Language filter

Switzerland's multilingual nature (FR/DE/IT/RM) makes language a meaningful filter. Other countries may not need it. Country-specific configuration handled per subdomain.

SEO

Each country page is server-rendered. Each club card has structured data. The canton/region filter works without JavaScript for crawlability. Club URLs are indexed directly by search engines.

D4 + D1 hybrid

The sidebar gives persistent, clear navigation for all pages. The D1-style centered hero makes the home page feel dignified and spacious — the club's identity takes center stage immediately.

Logo placement

"Powered by" placement

Sits at the bottom of the sidebar — persistent, never intrusive, always present. Every page view surfaces it to visitors without it dominating the club's content.

Admin section in sidebar

Only visible in edit mode — admins discover it naturally when they activate editing. Contains: accent color picker, account, version history, custom domain, data export. Collapses when in public view.

Live preview

The preview panel shows the actual club site miniature below the edit fields, updating as the admin types. Closing the cognitive gap between "what I'm editing" and "what visitors will see" without leaving the page.

Lock icons

Home and Contact have lock icons — immovable anchor pages. The toggle on/off for optional pages makes activation/deactivation instant and visual. "Add custom page" creates a new page slot.

Sidebar consistency

Same dark sidebar pattern as the club site edit mode — one visual language across both operator and admin interfaces. Section labels (Overview / Clubs / Platform) map cleanly to operator mental model.

Approve in-row

Approve/Reject actions live directly in the table row — no modal, no separate page. Low-volume workflow; operator makes the decision in one glance. Approval triggers automated subdomain provisioning + email.

Calm by default

The metrics panel is the most prominent element — showing platform health at a glance. If everything is green, the operator closes the tab. The amber support-ticket dot is the only signal requiring attention today.
